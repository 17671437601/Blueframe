# BlueFrame Studio 已知限制

本文件记录完整范围验收时确认的边界与未覆盖项。未列出的能力以自动化测试和 `docs/acceptance-report.md` 为准。

## 1. 账号与授权

- 当前使用 `StandaloneAccountService` 本地占位实现，没有接入真实账号服务、登录页或远程权益校验。
- `/api/v1/account/access` 固定返回 `mode=online`、`remote_ai=false`；远程 AI 是否可用由 Provider 配置决定，不由账号接口反映。
- 72 小时离线宽限与只读降级的契约和状态机已实现并有测试，但尚未接入真实 `AuthProvider` 服务端。
- 未实现并发上限、每日/每月额度、可用 AI/TTS 档位等 `Entitlements` 的运行时强制执行。

## 2. 远程 AI 与 TTS

- 远程 AI 仅实现火山引擎方舟 Responses API，没有其他模型供应商适配器。
- 默认由客户端直接调用方舟，未内置用户自有服务端代理；API Key 由用户提供并保存在本机 Windows 凭据管理器。
- 未实现调用成本预算、额度提示或自动停用。
- TTS 仅实现火山引擎 Seed-TTS 2.0 V3 HTTP Chunked 接口；其他语音供应商未接入。

## 3. AI 质量验收

- 本环境没有用户授权的真实剧集黄金数据集，未执行 10 部流程集或 30–50 部稳定版人工基线。
- 黄金媒体测试使用 FFmpeg `lavfi` 合成素材，Provider 测试使用固定假响应；这验证了确定性与契约，不等同于内容质量验收。
- 爆点、重组、解说文案的质量阈值尚未在真实素材上校准。
- 本地 ASR 运行时（FunASR + 模型）已打包并通过导入自检，但验收未执行真实音频转写；端到端识别质量需要在授权音频样本上另行确认。
- 火山方舟与 TTS 未产生真实计费调用，接口行为由假响应覆盖。

## 4. 直播切片

- 仅实现抖音授权播放地址适配器（`DouyinAuthorizedAdapter`），且要求用户确认拥有录制权利。
- 快手、虎牙、斗鱼、Bilibili、小红书、YY、TikTok 尚未实现。
- 不抓取页面、不提取私有签名、不接管 Cookie、不绕过付费、登录或 DRM。
- 平台地址过期后需要用户重新提供有效地址；平台规则变化可能导致录制失败。

## 5. 旧版数据导入

- 仅识别 `drama_project` 与 `movie_project` 两张表，且必须包含预期列；部分或未知 schema 会跳过并在预览中警告。
- 不导入旧版 ASR 缓存、分析结果、时间线、历史输出或素材库，只导入项目元数据并登记源文件。
- 不导入账号、会员、密钥、Cookie、通知等表。
- 导入为单向操作，不向旧库回写；重复导入幂等跳过，不覆盖新版本项目。

## 6. 素材中心

- 仅支持从本地目录导入素材并记录来源、许可证与内容指纹。
- 未提供可选在线素材包、主题市场或内置 CC0 素材下载。
- 大体积装饰素材需要用户自行准备，未随离线包分发。

## 7. 硬件与媒体

- 硬件编码探测失败时回退软件编码；未在所有 GPU、驱动和分辨率组合上验证。
- 硬件与软件编码共享同一滤镜图，画质差异仅来自编码器参数。
- UI 文件对话框列出 `mp4/mov/mkv/avi/m4v`；实际可解码范围取决于内置 FFmpeg，未穷举全部编解码器、可变帧率与 HDR 组合。
- 应用层已覆盖超过 260 字符的路径，但操作系统仍需启用 `LongPathsEnabled` 才能稳定使用超长路径。

## 8. 打包与分发

- 使用 PowerShell 安装脚本，不提供 MSI/MSIX 安装包。
- 未做代码签名，Windows SmartScreen 可能提示未知发布者。
- 未实现自动更新或增量更新；升级需要重新分发约 1.9 GB 的完整离线包。
- 离线包固定使用 Python 3.11 构建；不支持在运行时切换 Python 或模型版本。

## 9. 运行时行为

- 本地 worker 为单线程，同一时间只执行一个任务；没有多进程并行渲染。
- 没有单实例互斥锁；重复启动可能产生两个共享同一数据库的实例。
- 没有系统托盘；关闭窗口即停止本地后端与 worker。
- 没有操作系统通知，进度与失败信息只在界面和诊断包中呈现。
- 结构化指标写入数据库并通过诊断包导出，没有滚动文本日志文件。
- 仅提供中文界面和浅色主题。

## 10. 数据与运维

- 没有自动备份或定时快照；需要运维人员手动复制数据目录。
- 卸载会保留 `%LOCALAPPDATA%\BlueFrameStudio\data`，但不会提示用户是否删除。
- 本次修复前构建的旧安装包曾把数据放在 `_internal\.blueframe-data`；升级到本版本后需要手动把旧数据迁移到 `%LOCALAPPDATA%\BlueFrameStudio\data`。
- 数据库为单机 SQLite，不支持多用户共享或远程协作。
